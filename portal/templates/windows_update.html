Fonctionnement

  1. Le DNS du réseau répond {{ host }} pour les domaines de la liste (script ci-dessus pour un DNS Active Directory).
  2. Les postes Windows envoient donc leurs téléchargements à ce serveur au lieu de Microsoft.
  3. Le premier téléchargement d'un fichier part chez Microsoft et reste en cache ; les suivants sont servis en local.
  4. Le HTTPS de ces domaines est relayé sans être déchiffré ni mis en cache. Seuls les fichiers immuables sont gardés.
